    Method references
      Appendix · evidence

      Where every number comes from.

      Persona attributes by evidence kind

      Panel structure

      883 agents. Class mix and AUM/flow weights come from published market-share aggregates (Fed Z.1 fund-flow categories, SCF/ICI ownership surveys), coarse by construction.

      Behavioural parameters

      Attention, news sensitivity, disposition, herding and risk aversion are literature priors from behavioural-finance and brokerage-activity studies, deliberately uncalibrated. Every parameter carries a field-level evidence record.

      Identity cards

      Archetype templates plus deterministic variation; no field is copied from a real person. The attributes a real person would fill stay unset and are counted, never invented.

      Agent cards · one per role

      Red lines

      • Direction and ranking only. No effect sizes, no point predictions.
      • Model output is not evidence; rationale text is audit material.
      • Instability across models, prompts and seeds is a deliverable.
      • An A/B pair that is not identical before the intervention is flagged, never averaged in silently.

      Reproducibility

      • Five-tuple manifest: population × intervention × mechanism × model × seed.
      • Every intent carries provider, model, prompt version and prompt hash.
      • Manifests carry a code hash over runtime/, experiments/ and evidence/.
      • Real-brain responses are cached by prompt hash, so a re-run replays them.
